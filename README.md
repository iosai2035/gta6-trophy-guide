An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words with named sources, a spoiler setting that hides unrevealed trophies until earned, filters and search, a saved-progress tracker with export and import, the roadmap to the platinum (including the one missable trophy), and the full 35-item 100% completion checklist for A Long Road.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide works with the network off.
